# arm-mind v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude controls a simulated Franka Panda arm in MuJoCo through gripper targets, and you watch each step live in a browser.

**Architecture:** A Python package `armmind`. MuJoCo runs headless on one dedicated thread. An agent loop asks Claude (through the Claude Code CLI) for a short JSON plan while the physics stands still, then runs the actions. A FastAPI server sends camera frames and step events to one browser page through a WebSocket.

**Tech Stack:** Python 3.12, uv, MuJoCo 3.x (EGL off-screen rendering), NumPy, Pillow, FastAPI, uvicorn, pytest, ruff. Vanilla HTML and JavaScript for the page.

**Spec:** `docs/superpowers/specs/2026-10-16-arm-mind-v1-design.md`

## Global Constraints

- Python `>=3.12`. Use `uv sync` and `uv run ...` for every Python command. Never use the system Python.
- `MUJOCO_GL` defaults to `egl`. `src/armmind/__init__.py` sets it before any `mujoco` import.
- The server port is `8780`. The CLI must refuse port `8765`, because ps1-mind uses it.
- Never commit the robot model. `scripts/fetch_assets.sh` downloads it into `assets/`, and `.gitignore` excludes `assets/` and `runs/`.
- Every MuJoCo call for one run (world, renderer, arm) happens on one thread: `SimThread`. The EGL context works only on the thread that made it.
- Commit messages: a short `type: summary` line. Do not add `Claude-Session`, `Co-Authored-By` or `Generated with` lines.
- Prose (comments, docs, commit messages, prompt text) uses simple English: active voice, short sentences, no semicolons.
- Units are metres in the world frame. The robot base is at the origin. The table surface is at `z = 0`.
- The workspace box is `x 0.25..0.75`, `y -0.40..0.40`, `z 0.01..0.50`.
- A step holds at most 8 actions. A `wait` lasts at most 3 seconds.

## Review Focus

1. **Renderer on the wrong thread.** If a run calls the renderer from a second thread, the frames go black or the process crashes. Expect: all calls go through `SimThread`. Test: `test_sim_thread_uses_one_thread` (Task 5).
2. **A browser tab closes during a run.** Expect: the run continues, and the hub removes the dead socket. Test: `test_hub_drops_dead_socket` (Task 9).
3. **Start pressed twice.** Expect: the second request gets HTTP 409, and only one simulation runs. Test: `test_second_run_is_rejected` (Task 9).
4. **Bad numbers from the model** (NaN, strings, a point outside the workspace, more than 8 actions). Expect: a clear `ReplyError` and one retry, or a clamp with a note. Never a crash. Tests: `test_parse_*` (Task 7) and `test_move_to_clamps_to_workspace` (Task 3).
5. **Stop pressed while Claude thinks.** Expect: the run ends within about 1 second with status `stopped`, and the CLI process stops. Test: `test_stop_while_model_thinks` (Task 8).

```python
"""MuJoCo world: the Panda arm, a table and three cubes."""
from __future__ import annotations

import shutil
from pathlib import Path

import mujoco
import numpy as np

from armmind.sim.assets import panda_dir

SCENE = Path(__file__).with_name("scene.xml")
CUBES = ("red_cube", "blue_cube", "green_cube")
CUBE_HALF = 0.02
TCP_OFFSET = np.array([0.0, 0.0, 0.1034])  # from the hand frame to the point between the fingertips
GRIPPER_BODIES = ("hand", "left_finger", "right_finger")

Layout = dict[str, tuple[float, float]]


class World:
    def __init__(self, model_dir: Path | None = None):
        folder = model_dir or panda_dir()
        scene = folder / "armmind_scene.xml"
        shutil.copyfile(SCENE, scene)  # MJCF resolves <include> next to the scene file
        self.model = mujoco.MjModel.from_xml_path(str(scene))
        self.data = mujoco.MjData(self.model)
        self.hand_id = self.model.body("hand").id
        self._gripper = {self.model.body(n).id for n in GRIPPER_BODIES}

    @property
    def dt(self) -> float:
        return float(self.model.opt.timestep)

    @property
    def time(self) -> float:
        return float(self.data.time)

    def reset(self, layout: Layout) -> None:
        missing = sorted(set(CUBES) - set(layout))
        if missing:
            raise ValueError(f"layout misses {missing}")
        mujoco.mj_resetDataKeyframe(self.model, self.data, 0)
        for name in CUBES:
            adr = self.model.jnt_qposadr[self.model.joint(name).id]
            x, y = layout[name]
            self.data.qpos[adr:adr + 7] = [x, y, CUBE_HALF, 1, 0, 0, 0]
        mujoco.mj_forward(self.model, self.data)

    def step(self, n: int = 1) -> None:
        mujoco.mj_step(self.model, self.data, nstep=n)

    def tcp(self) -> np.ndarray:
        rot = self.data.xmat[self.hand_id].reshape(3, 3)
        return self.data.xpos[self.hand_id] + rot @ TCP_OFFSET

    def gripper_width(self) -> float:
        return float(self.data.qpos[7] + self.data.qpos[8])

    def cube_pos(self, name: str) -> np.ndarray:
        return self.data.body(name).xpos.copy()

    def gripper_contacts(self) -> list[str]:
        body = self.model.geom_bodyid
        names: set[str] = set()
        for g1, g2 in zip(self.data.contact.geom1, self.data.contact.geom2, strict=True):
            for mine, other in ((body[g1], body[g2]), (body[g2], body[g1])):
                if mine in self._gripper and other not in self._gripper:
                    names.add("table" if other == 0 else self.model.body(other).name)
        return sorted(names)
```

`src/armmind/sim/render.py`:

```python
"""Camera images and a coordinate grid drawn on the table."""
from __future__ import annotations

import io

import mujoco
import numpy as np
from PIL import Image, ImageDraw

from armmind.sim.world import World

GRID_X = [round(0.2 + 0.1 * i, 1) for i in range(7)]  # 0.2 .. 0.8
GRID_Y = [round(-0.4 + 0.1 * i, 1) for i in range(9)]  # -0.4 .. 0.4
LINE = (30, 30, 30)
TEXT = (0, 0, 0)


def _label(v: float) -> str:
    return f"{v + 0.0:.1f}"  # + 0.0 turns -0.0 into 0.0


class Cameras:
    """Use one instance on one thread only. The EGL context belongs to the thread that made it."""

    def __init__(self, world: World, width: int = 640, height: int = 480):
        self.world, self.w, self.h = world, width, height
        self._r = mujoco.Renderer(world.model, height, width)

    def render(self, cam: str) -> np.ndarray:
        self._r.update_scene(self.world.data, camera=cam)
        return self._r.render().copy()

    def project(self, cam: str, points) -> np.ndarray:
        m, d = self.world.model, self.world.data
        cid = m.camera(cam).id
        rot = d.cam_xmat[cid].reshape(3, 3)
        v = (np.asarray(points, dtype=float) - d.cam_xpos[cid]) @ rot  # rows are rot.T @ (p - pos)
        depth = -v[:, 2]  # a MuJoCo camera looks along its -z axis
        f = (self.h / 2) / np.tan(np.radians(m.cam_fovy[cid]) / 2)
        with np.errstate(divide="ignore", invalid="ignore"):
            out = np.stack([self.w / 2 + f * v[:, 0] / depth, self.h / 2 - f * v[:, 1] / depth], axis=1)
        out[depth <= 1e-6] = np.nan
        return out

    def with_grid(self, cam: str) -> Image.Image:
        img = Image.fromarray(self.render(cam))
        draw = ImageDraw.Draw(img)
        for x in GRID_X:
            a, b = self.project(cam, [[x, GRID_Y[0], 0], [x, GRID_Y[-1], 0]])
            draw.line([tuple(a), tuple(b)], fill=LINE, width=1)
            draw.text((a[0] - 34, a[1] - 6), f"x={_label(x)}", fill=TEXT)
        for y in GRID_Y:
            a, b = self.project(cam, [[GRID_X[0], y, 0], [GRID_X[-1], y, 0]])
            draw.line([tuple(a), tuple(b)], fill=LINE, width=1)
            draw.text((a[0] - 14, a[1] - 14), f"y={_label(y)}", fill=TEXT)
        return img

    def close(self) -> None:
        self._r.close()  # without this, Python prints EGL errors at exit


def png(img: Image.Image) -> bytes:
    buf = io.BytesIO()
    img.save(buf, format="PNG")
    return buf.getvalue()


def jpeg(arr: np.ndarray, quality: int = 70) -> bytes:
    buf = io.BytesIO()
    Image.fromarray(arr).save(buf, format="JPEG", quality=quality)
    return buf.getvalue()
```

```python
from typing import Literal

ActionType = Literal["move_to", "open", "close", "wait"]
Status = Literal["reached", "blocked", "unreachable"]
Vec3 = tuple[float, float, float]


def fmt(p) -> str:
    return f"({p[0]:.3f}, {p[1]:.3f}, {p[2]:.3f})"


@dataclass(frozen=True)
class Action:
    type: ActionType
    xyz: Vec3 | None = None
    seconds: float = 0.5

    def describe(self) -> str:
        if self.type == "move_to":
            return f"move_to{fmt(self.xyz)}"
        if self.type == "wait":
            return f"wait({self.seconds:.1f} s)"
        return self.type


@dataclass(frozen=True)
class ActionResult:
    action: Action
    status: Status
    tcp: Vec3
    gripper_width: float
    contacts: tuple[str, ...] = ()
    note: str = ""

    def summary(self) -> str:
        s = (f"{self.action.describe()}: {self.status}, gripper at {fmt(self.tcp)}, "
             f"width {self.gripper_width:.3f}")
        if self.contacts:
            s += f", touching {', '.join(self.contacts)}"
        if self.note:
            s += f" ({self.note})"
        return s


@dataclass(frozen=True)
class Observation:
    front_png: bytes
    top_png: bytes
    tcp: Vec3
    gripper_width: float
    contacts: tuple[str, ...]
    objects: dict[str, Vec3] | None = None  # only with the debug switch on
```

```python
"""Moves the gripper to targets. IK finds joint angles, and the joint controllers follow a smooth path."""
from __future__ import annotations

from collections.abc import Callable

import mujoco
import numpy as np

from armmind.sim.world import TCP_OFFSET, World
from armmind.types import Action, ActionResult, Status

WORKSPACE_LO = np.array([0.25, -0.40, 0.01])
WORKSPACE_HI = np.array([0.75, 0.40, 0.50])
READY = np.array([0.30, 0.0, 0.40])
SPEED = 0.25  # m/s along the straight distance
SETTLE_S = 0.3
GRIP_S = 0.6
GRIP_OPEN, GRIP_CLOSED = 255.0, 0.0
REACH_TOL = 0.02
MAX_WAIT_S = 3.0
FRAME_DT = 1 / 30


class Arm:
    def __init__(self, world: World, on_frame: Callable[[], None] | None = None):
        self.w, self.on_frame = world, on_frame
        self._ik = mujoco.MjData(world.model)  # scratch data: IK never moves the real arm
        mujoco.mj_resetDataKeyframe(world.model, self._ik, 0)
        mujoco.mj_kinematics(world.model, self._ik)
        self._rot0 = self._ik.xmat[world.hand_id].reshape(3, 3).copy()  # home: points down
        self._next_frame = 0.0

    def solve_ik(self, target) -> np.ndarray | None:
        m, d, hand = self.w.model, self._ik, self.w.hand_id
        d.qpos[:] = self.w.data.qpos
        jp, jr = np.zeros((3, m.nv)), np.zeros((3, m.nv))
        for _ in range(300):
            mujoco.mj_kinematics(m, d)
            mujoco.mj_comPos(m, d)
            rot = d.xmat[hand].reshape(3, 3)
            p = d.xpos[hand] + rot @ TCP_OFFSET
            err_p = target - p
            err_r = 0.5 * sum(np.cross(rot[:, i], self._rot0[:, i]) for i in range(3))
            if np.linalg.norm(err_p) < 1e-3 and np.linalg.norm(err_r) < 1e-2:
                return d.qpos[:7].copy()
            mujoco.mj_jac(m, d, jp, jr, p, hand)
            jac = np.vstack([jp, jr])[:, :7]
            dq = jac.T @ np.linalg.solve(jac @ jac.T + 1e-4 * np.eye(6), np.concatenate([err_p, err_r]))
            d.qpos[:7] = np.clip(d.qpos[:7] + dq, m.jnt_range[:7, 0], m.jnt_range[:7, 1])
        return None

    def reset_ready(self) -> None:
        q = self.solve_ik(READY)
        if q is None:
            raise RuntimeError("no IK solution for the ready pose")
        d = self.w.data
        d.qpos[:7] = q
        d.ctrl[:7] = q
        d.ctrl[7] = GRIP_OPEN
        mujoco.mj_forward(self.w.model, d)
        self._next_frame = self.w.time
        self._run(SETTLE_S)

    def act(self, action: Action) -> ActionResult:
        if action.type == "move_to":
            return self._move_to(action)
        if action.type in ("open", "close"):
            self.w.data.ctrl[7] = GRIP_CLOSED if action.type == "close" else GRIP_OPEN
            self._run(GRIP_S)
            return self._result(action, "reached")
        if action.type == "wait":
            self._run(min(max(action.seconds, 0.0), MAX_WAIT_S))
            return self._result(action, "reached")
        raise ValueError(f"unknown action type {action.type!r}")

    def _move_to(self, action: Action) -> ActionResult:
        want = np.asarray(action.xyz, dtype=float)
        target = np.clip(want, WORKSPACE_LO, WORKSPACE_HI)
        note = "target clamped to the workspace" if not np.allclose(target, want) else ""
        q_goal = self.solve_ik(target)
        if q_goal is None:
            return self._result(action, "unreachable", note or "no joint solution for this point")
        q0 = self.w.data.ctrl[:7].copy()
        duration = max(0.4, float(np.linalg.norm(target - self.w.tcp())) / SPEED)
        n = int(duration / self.w.dt)
        for i in range(1, n + 1):
            a = i / n
            self.w.data.ctrl[:7] = q0 + (a * a * (3 - 2 * a)) * (q_goal - q0)  # smoothstep
            self._step()
        self._run(SETTLE_S)
        reached = np.linalg.norm(self.w.tcp() - target) <= REACH_TOL
        return self._result(action, "reached" if reached else "blocked", note)

    def _result(self, action: Action, status: Status, note: str = "") -> ActionResult:
        p = self.w.tcp()
        return ActionResult(action, status, (round(float(p[0]), 3), round(float(p[1]), 3), round(float(p[2]), 3)),
                            round(self.w.gripper_width(), 3), tuple(self.w.gripper_contacts()), note)

    def _step(self) -> None:
        self.w.step()
        if self.on_frame is not None and self.w.time >= self._next_frame:
            self._next_frame = self.w.time + FRAME_DT
            self.on_frame()

    def _run(self, seconds: float) -> None:
        for _ in range(int(round(seconds / self.w.dt))):
            self._step()
```

```python
from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass

import numpy as np

from armmind.sim.world import CUBE_HALF, CUBES, Layout, World

MIN_GAP = 0.10


def random_layout(seed: int) -> Layout:
    rng = np.random.default_rng(seed)
    points: list[tuple[float, float]] = []
    while len(points) < len(CUBES):
        p = (round(float(rng.uniform(0.40, 0.65)), 3), round(float(rng.uniform(-0.25, 0.25)), 3))
        if all(np.hypot(p[0] - q[0], p[1] - q[1]) >= MIN_GAP for q in points):
            points.append(p)
    return dict(zip(CUBES, points, strict=True))


@dataclass(frozen=True)
class Task:
    name: str
    instruction: str
    success: Callable[[World], bool]

    def layout(self, seed: int) -> Layout:
        return random_layout(seed)


def _reach(w: World) -> bool:
    return "red_cube" in w.gripper_contacts()


def _pick(w: World) -> bool:
    return bool(w.cube_pos("red_cube")[2] >= CUBE_HALF + 0.10)


def _stack(w: World) -> bool:
    red, blue = w.cube_pos("red_cube"), w.cube_pos("blue_cube")
    on_top = np.hypot(*(red[:2] - blue[:2])) < 0.02 and abs(red[2] - (blue[2] + 2 * CUBE_HALF)) < 0.01
    return bool(on_top and "red_cube" not in w.gripper_contacts())


TASKS: dict[str, Task] = {t.name: t for t in (
    Task("reach", "Touch the red cube with the gripper.", _reach),
    Task("pick", "Pick up the red cube and lift it at least 10 cm above the table.", _pick),
```

```python
from __future__ import annotations

from armmind.sim.world import World
from armmind.types import Action


def scripted_plan(task: str, world: World) -> list[Action]:
    red, blue = world.cube_pos("red_cube"), world.cube_pos("blue_cube")

    def above(p, z: float) -> Action:
        return Action("move_to", (float(p[0]), float(p[1]), z))

    grasp = [Action("open"), above(red, 0.15), above(red, 0.02), Action("close")]
    plans = {
        "reach": [Action("close"), above(red, 0.15), above(red, 0.04)],
        "pick": [*grasp, above(red, 0.20)],
        "stack": [*grasp, above(red, 0.15), above(blue, 0.15), above(blue, 0.065), Action("open"),
                  above(blue, 0.15)],
    }
    return plans[task]
```

```python
from __future__ import annotations

import argparse

from armmind.tasks import TASKS


def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(prog="armmind")
    sub = p.add_subparsers(dest="cmd", required=True)
    s = sub.add_parser("scripted", help="run the hard-coded plan for a task")
    s.add_argument("--task", choices=sorted(TASKS), required=True)
    s.add_argument("--seed", type=int, default=0)
    args = p.parse_args(argv)
    return _scripted(args.task, args.seed)


def _scripted(task: str, seed: int) -> int:
    from armmind.policy.scripted import scripted_plan
    from armmind.sim.arm import Arm
    from armmind.sim.world import World

    w = World()
    w.reset(TASKS[task].layout(seed))
    arm = Arm(w)
    arm.reset_ready()
    for action in scripted_plan(task, w):
        print(arm.act(action).summary())
    ok = TASKS[task].success(w)
    print("success" if ok else "failed")
    return 0 if ok else 1
```

```python
"""The interface between the agent and a world, and the MuJoCo version of it."""
from __future__ import annotations

import asyncio
from collections.abc import Callable
from concurrent.futures import ThreadPoolExecutor
from typing import Protocol

from armmind.sim.arm import Arm
from armmind.sim.render import Cameras, jpeg, png
from armmind.sim.world import CUBES, World
from armmind.tasks import Task
from armmind.types import Action, ActionResult, Observation


class Env(Protocol):
    instruction: str

    def observe(self) -> Observation: ...
    def act(self, action: Action) -> ActionResult: ...
    def success(self) -> bool: ...
    def close(self) -> None: ...


def _r3(p) -> tuple[float, float, float]:
    return (round(float(p[0]), 3), round(float(p[1]), 3), round(float(p[2]), 3))


class MujocoEnv:
    """Make it and use it on one thread only (see SimThread)."""

    def __init__(self, task: Task, seed: int, show_positions: bool = False,
                 on_frame: Callable[[bytes], None] | None = None):
        self.task, self.instruction, self.show_positions = task, task.instruction, show_positions
        self.world = World()
        self.world.reset(task.layout(seed))
        self.cams = Cameras(self.world)
        self._on_frame = on_frame
        self.arm = Arm(self.world, on_frame=self._frame if on_frame else None)
        self.arm.reset_ready()

    def _frame(self) -> None:
        self._on_frame(jpeg(self.cams.render("front")))

    def observe(self) -> Observation:
        objects = {n: _r3(self.world.cube_pos(n)) for n in CUBES} if self.show_positions else None
        return Observation(
            front_png=png(self.cams.with_grid("front")), top_png=png(self.cams.with_grid("top")),
            tcp=_r3(self.world.tcp()), gripper_width=round(self.world.gripper_width(), 3),
            contacts=tuple(self.world.gripper_contacts()), objects=objects)

    def act(self, action: Action) -> ActionResult:
        return self.arm.act(action)

    def success(self) -> bool:
        return bool(self.task.success(self.world))

    def close(self) -> None:
        self.cams.close()


class SimThread:
    """Runs every call on one worker thread. MuJoCo's EGL renderer works only on the thread that made it."""

    def __init__(self):
        self._ex = ThreadPoolExecutor(max_workers=1, thread_name_prefix="sim")

    async def call(self, fn, *args):
        return await asyncio.get_running_loop().run_in_executor(self._ex, fn, *args)

    def shutdown(self) -> None:
        self._ex.shutdown(wait=True)
```

```python
"""Checks the model's JSON reply and turns it into actions."""
from __future__ import annotations

import math
from dataclasses import dataclass

from armmind.types import Action

MAX_WAIT_S = 3.0


class ReplyError(ValueError):
    pass


@dataclass(frozen=True)
class Reply:
    observation: str
    plan: str
    actions: tuple[Action, ...]
    notes: str | None
    todo: tuple[str, ...]
    truncated: bool = False


def _number(v) -> bool:
    return isinstance(v, int | float) and not isinstance(v, bool) and math.isfinite(v)


def _action(i: int, a) -> Action:
    if not isinstance(a, dict):
        raise ReplyError(f"action {i} is not an object")
    kind = a.get("type")
    if kind == "move_to":
        xyz = a.get("xyz")
        if not (isinstance(xyz, list) and len(xyz) == 3 and all(_number(v) for v in xyz)):
            raise ReplyError(f"action {i}: move_to needs 'xyz' with 3 finite numbers")
        return Action("move_to", (float(xyz[0]), float(xyz[1]), float(xyz[2])))
    if kind in ("open", "close"):
        return Action(kind)
    if kind == "wait":
        s = a.get("seconds", 0.5)
        if not _number(s):
            raise ReplyError(f"action {i}: wait needs 'seconds' as a number")
        return Action("wait", seconds=min(max(float(s), 0.0), MAX_WAIT_S))
    raise ReplyError(f"action {i}: unknown type {kind!r}")


def parse_reply(obj, max_actions: int = 8) -> Reply:
    if not isinstance(obj, dict):
        raise ReplyError("the reply is not a JSON object")
    raw = obj.get("actions")
    if not isinstance(raw, list):
        raise ReplyError("'actions' must be a list")
    actions = [_action(i, a) for i, a in enumerate(raw)]
    todo = obj.get("todo") or []
    if not isinstance(todo, list) or not all(isinstance(t, str) for t in todo):
        raise ReplyError("'todo' must be a list of strings")
    notes = obj.get("notes")
    if notes is not None and not isinstance(notes, str):
        raise ReplyError("'notes' must be a string")
    return Reply(str(obj.get("observation", "")), str(obj.get("plan", "")), tuple(actions[:max_actions]),
                 notes, tuple(todo[:5]), len(actions) > max_actions)
```

```python
"""The system prompt, the reply schema and the text of each step's message."""
from __future__ import annotations

from dataclasses import dataclass

from armmind.types import Observation, fmt

SYSTEM = """\
You control a Franka Panda robot arm in a physics simulation. Each step, you get two camera images \
and the state of the gripper. You reply with a short plan and a list of actions.

Coordinates are in metres, in the world frame:
- The robot base is at x=0, y=0. The table surface is at z=0.
- +x points away from the robot. +y points to the right in both images.
- In the top image, +x points down. In the front image, +x points toward the camera.
- Both images have a grid on the table, with labels for x and y. Use it to find positions.

The cubes are 4 cm wide. The centre of a cube on the table is at z=0.02.
The gripper position is the point between the two fingertips. The gripper always points down.
The gripper is 0.08 m wide when open. When it closes on a cube, the width is about 0.04 m. \
When it closes on nothing, the width is about 0.

Actions:
- {"type": "move_to", "xyz": [x, y, z]}: move the gripper to this point.
- {"type": "open"} and {"type": "close"}: open or close the gripper.
- {"type": "wait", "seconds": s}: wait for s seconds (at most 3).
The arm can reach x from 0.25 to 0.75, y from -0.40 to 0.40, z from 0.01 to 0.50. \
The arm moves a target outside this box to the nearest point inside it.
To grasp a cube: open, move 10 cm above it, move down to its centre, close, then move up.
Each result says if the gripper reached the target, was blocked, or could not reach it.

The simulation stops while you think. Use at most 8 actions in each step. \
Write "observation" in 2 short sentences and "plan" in 1 sentence. \
Write "notes" only when something worth remembering changed. \
Keep a "todo" list of 3 to 5 short sub-goals."""

REPLY_SCHEMA = {
    "type": "object",
    "additionalProperties": False,
    "required": ["observation", "plan", "actions", "todo"],
    "properties": {
        "observation": {"type": "string"},
        "plan": {"type": "string"},
        "actions": {
            "type": "array",
            "maxItems": 8,
            "items": {
                "type": "object",
                "additionalProperties": False,
                "required": ["type"],
                "properties": {
                    "type": {"enum": ["move_to", "open", "close", "wait"]},
                    "xyz": {"type": "array", "items": {"type": "number"}, "minItems": 3, "maxItems": 3},
                    "seconds": {"type": "number"},
                },
            },
        },
        "notes": {"type": "string"},
        "todo": {"type": "array", "items": {"type": "string"}, "maxItems": 5},
    },
}


@dataclass(frozen=True)
class StepSummary:
    step: int
    plan: str
    results: tuple[str, ...]


def build_user_text(instruction: str, step: int, max_steps: int, obs: Observation, notes: str,
                    todo: tuple[str, ...], history: list[StepSummary]) -> str:
    lines = [
        f"Task: {instruction}",
        f"Step {step} of {max_steps}.",
        f"Gripper at {fmt(obs.tcp)}, width {obs.gripper_width:.3f} m.",
        f"Gripper touching: {', '.join(obs.contacts) if obs.contacts else 'nothing'}.",
    ]
    if obs.objects is not None:
        lines.append("Cube centres (debug): " + "; ".join(f"{n} {fmt(p)}" for n, p in obs.objects.items()))
    if history:
        lines.append("Recent steps:")
        lines += [f"- step {h.step}: {h.plan} -> {'; '.join(h.results) or 'no actions'}" for h in history]
    lines.append(f"Your notes: {notes or '(empty)'}")
    lines.append("Your to-do list: " + ("; ".join(todo) if todo else "(empty)"))
    lines.append("Image 1: front camera. Image 2: top camera.")
    return "\n".join(lines)
```

```python
"""The agent loop: observe, ask the model, act. The physics stands still while the model thinks."""
from __future__ import annotations

import asyncio
from collections import deque
from collections.abc import Awaitable, Callable
from dataclasses import dataclass

from armmind.agent.parse import Reply, ReplyError, parse_reply
from armmind.agent.prompts import REPLY_SCHEMA, SYSTEM, StepSummary, build_user_text
from armmind.env import Env
from armmind.llm.protocol import Conversation, Final, LLMBackend, LLMError, Message, Usage

Emit = Callable[[str, dict], None]
Call = Callable[..., Awaitable]


@dataclass(frozen=True)
class AgentConfig:
    max_steps: int = 30
    history_steps: int = 5
    max_actions: int = 8


class Agent:
    def __init__(self, backend: LLMBackend, config: AgentConfig = AgentConfig()):
        self.backend, self.cfg = backend, config
        self._stop = asyncio.Event()
        self._conv: Conversation | None = None

    async def stop(self) -> None:
        self._stop.set()
        if self._conv is not None:
            await self._conv.cancel()

    async def run(self, env: Env, call: Call, emit: Emit) -> str:
        self._conv = await self.backend.open(SYSTEM)
        history: deque[StepSummary] = deque(maxlen=self.cfg.history_steps)
        notes, todo, status = "", (), "step_limit"
        emit("run_start", {"instruction": env.instruction, "max_steps": self.cfg.max_steps})
        try:
            for n in range(1, self.cfg.max_steps + 1):
                if self._stop.is_set():
                    status = "stopped"
                    break
                obs = await call(env.observe)
                emit("observation", {"step": n, "front_png": obs.front_png, "top_png": obs.top_png})
                text = build_user_text(env.instruction, n, self.cfg.max_steps, obs, notes, todo, list(history))
                reply, error, usage = await self._ask(Message("user", text, (obs.front_png, obs.top_png)))
                if self._stop.is_set():
                    status = "stopped"
                    break
                if reply is None and error is not None and error.kind != "schema":
                    emit("llm_error", {"step": n, "kind": error.kind, "message": error.message})
                    status = "llm_error"
                    break
                if reply is None:
                    emit("bad_reply", {"step": n, "error": error.message if error else "no reply"})
                    continue
                emit("reply", {"step": n, "plan": reply.plan, "actions": [a.describe() for a in reply.actions]})
                results = []
                for action in reply.actions:
                    if self._stop.is_set():
                        break
                    results.append(await call(env.act, action))
                    if await call(env.success):
                        break
                if reply.notes is not None:
                    notes = reply.notes
                todo = reply.todo or todo
                history.append(StepSummary(n, reply.plan, tuple(r.summary() for r in results)))
                done = await call(env.success)
                emit("step", {
                    "step": n, "observation": reply.observation, "plan": reply.plan,
                    "actions": [a.describe() for a in reply.actions], "results": [r.summary() for r in results],
                    "truncated": reply.truncated, "notes": notes, "todo": list(todo), "success": done,
                    "latency_s": usage.latency_s if usage else None, "cost_usd": usage.cost_usd if usage else None,
                })
                if done:
                    status = "success"
                    break
            else:
                if self._stop.is_set():
                    status = "stopped"
        finally:
            await self._conv.close()
        emit("run_end", {"status": status})
        return status

    async def _ask(self, msg: Message) -> tuple[Reply | None, LLMError | None, Usage | None]:
        reply, error, usage = await self._send(msg)
        if error is not None and error.kind == "schema" and not self._stop.is_set():
            retry = Message("user", f"Your last reply was not valid: {error.message[:300]}. "
                                    "Reply again in the required format.")
            reply, error, usage = await self._send(retry)
        return reply, error, usage

    async def _send(self, msg: Message) -> tuple[Reply | None, LLMError | None, Usage | None]:
        final, usage, error = None, None, None
        async for ev in self._conv.send(msg, REPLY_SCHEMA):
            if isinstance(ev, Final):
                final = ev
            elif isinstance(ev, Usage):
                usage = ev
            elif isinstance(ev, LLMError):
                error = ev
        if error is not None:
            return None, error, usage
        if final is None or final.parsed is None:
            return None, LLMError("schema", "no structured answer"), usage
        try:
            return parse_reply(final.parsed, self.cfg.max_actions), None, usage
        except ReplyError as e:
            return None, LLMError("schema", str(e)), usage
```

```python
"""One folder for each run: events.jsonl and the observation images."""
from __future__ import annotations

import json
import time
from pathlib import Path


class RunLog:
    def __init__(self, root: Path):
        stamp = time.strftime("%Y%m%d-%H%M%S")
        n = 0
        while True:
            folder = Path(root) / (stamp if n == 0 else f"{stamp}-{n}")
            try:
                folder.mkdir(parents=True)
                break
            except FileExistsError:
                n += 1
        self.dir = folder
        self._f = (folder / "events.jsonl").open("a", encoding="utf-8")

    def event(self, kind: str, data: dict) -> dict:
        record: dict = {"t": round(time.time(), 3), "kind": kind}
        for key, value in data.items():
            if isinstance(value, bytes) and key.endswith("_png"):
                name = f"step{int(data.get('step', 0)):03d}_{key.removesuffix('_png')}.png"
                (self.dir / name).write_bytes(value)
                value = name
            record[key] = value
        self._f.write(json.dumps(record) + "\n")
        self._f.flush()
        return record

    def close(self) -> None:
        self._f.close()
```

```python
"""HTTP and WebSocket server. One run at a time. Frames and events go to every open page."""
from __future__ import annotations

import asyncio
import base64
import time
from collections.abc import Callable
from contextlib import asynccontextmanager
from pathlib import Path

from fastapi import FastAPI, HTTPException, WebSocket, WebSocketDisconnect
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel, Field

from armmind.agent.loop import Agent, AgentConfig
from armmind.env import Env, SimThread
from armmind.llm.protocol import LLMBackend
from armmind.store.runlog import RunLog
from armmind.tasks import TASKS, Task

WEB_DIR = Path(__file__).resolve().parents[3] / "web"
EnvFactory = Callable[[Task, int, bool, Callable[[bytes], None]], Env]


class RunRequest(BaseModel):
    task: str
    seed: int = Field(0, ge=0)
    max_steps: int = Field(30, ge=1, le=200)
    show_positions: bool = False
    instruction: str | None = Field(None, max_length=500)  # replaces the task's text, the success check stays


class Hub:
    def __init__(self):
        self.clients: set = set()
        self.loop: asyncio.AbstractEventLoop | None = None

    async def publish(self, msg: dict) -> None:
        for ws in list(self.clients):
            try:
                await ws.send_json(msg)
            except Exception:  # a closed tab must not stop the run
                self.clients.discard(ws)

    def publish_threadsafe(self, msg: dict) -> None:
        if self.loop is not None:
            asyncio.run_coroutine_threadsafe(self.publish(msg), self.loop)


class Pacer:
    """Sleeps on the sim thread between frames, so that the motion plays at real time."""

    def __init__(self, dt: float = 1 / 30):
        self.dt, self._last = dt, None

    def __call__(self) -> None:
        now = time.monotonic()
        if self._last is not None and (wait := self.dt - (now - self._last)) > 0:
            time.sleep(wait)
            now += wait
        self._last = now


def default_env_factory(task: Task, seed: int, show_positions: bool, on_frame: Callable[[bytes], None]) -> Env:
    from armmind.env import MujocoEnv
    return MujocoEnv(task, seed, show_positions=show_positions, on_frame=on_frame)


def _b64(b: bytes) -> str:
    return base64.b64encode(b).decode()


class Runner:
    def __init__(self, backend: LLMBackend, env_factory: EnvFactory, runs_dir: Path, hub: Hub):
        self.backend, self.env_factory, self.runs_dir, self.hub = backend, env_factory, runs_dir, hub
        self.task: asyncio.Task | None = None
        self.agent: Agent | None = None
        self.run_dir: Path | None = None

    @property
    def running(self) -> bool:
        return self.task is not None and not self.task.done()

    async def start(self, req: RunRequest, task: Task) -> Path:
        if self.running:
            raise HTTPException(409, "a run is already active")
        log = RunLog(self.runs_dir)
        self.run_dir = log.dir
        pacer = Pacer()

        def on_frame(jpg: bytes) -> None:
            self.hub.publish_threadsafe({"type": "frame", "jpg": _b64(jpg)})
            pacer()

        def emit(kind: str, data: dict) -> None:
            msg = {"type": "event", **log.event(kind, data)}
            for key, value in data.items():
                if isinstance(value, bytes):
                    msg[key] = _b64(value)
            self.hub.publish_threadsafe(msg)

        self.agent = Agent(self.backend, AgentConfig(max_steps=req.max_steps))
        agent = self.agent

        async def go() -> None:
            sim, env = SimThread(), None
            try:
                env = await sim.call(self.env_factory, task, req.seed, req.show_positions, on_frame)
                if req.instruction and req.instruction.strip():
                    env.instruction = req.instruction.strip()
                await agent.run(env, sim.call, emit)
            except Exception as e:  # report and end the run, never kill the server
                emit("run_end", {"status": "error", "message": f"{type(e).__name__}: {e}"})
            finally:
                if env is not None:
                    await sim.call(env.close)
                sim.shutdown()
                log.close()

        self.task = asyncio.create_task(go())
        return log.dir

    async def stop(self) -> None:
        if self.agent is not None:
            await self.agent.stop()
        if self.task is not None:
            await asyncio.wait({self.task}, timeout=5)


def create_app(backend: LLMBackend, env_factory: EnvFactory | None = None, runs_dir: Path = Path("runs"),
               web_dir: Path = WEB_DIR) -> FastAPI:
    hub = Hub()
    runner = Runner(backend, env_factory or default_env_factory, Path(runs_dir), hub)

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        hub.loop = asyncio.get_running_loop()
        yield
        await runner.stop()

    app = FastAPI(lifespan=lifespan)

    @app.get("/api/tasks")
    def tasks() -> list[dict]:
        return [{"name": t.name, "instruction": t.instruction} for t in TASKS.values()]

    @app.get("/api/state")
    def state() -> dict:
        return {"running": runner.running, "run_dir": str(runner.run_dir) if runner.run_dir else None}

    @app.post("/api/run")
    async def run(req: RunRequest) -> dict:
        task = TASKS.get(req.task)
        if task is None:
            raise HTTPException(404, f"unknown task {req.task!r}")
        return {"run_dir": str(await runner.start(req, task))}

    @app.post("/api/stop")
    async def stop() -> dict:
        await runner.stop()
        return {"ok": True}

    @app.websocket("/ws")
    async def ws(sock: WebSocket) -> None:
        await sock.accept()
        hub.clients.add(sock)
        try:
            while True:
                await sock.receive_text()
        except WebSocketDisconnect:
            pass
        finally:
            hub.clients.discard(sock)

    app.mount("/", StaticFiles(directory=web_dir, html=True), name="web")
    app.state.runner, app.state.hub = runner, hub
    return app
```

```python
    p = argparse.ArgumentParser(prog="armmind")
```

```js
const $ = (id) => document.getElementById(id);
let tasks = [];

function setStatus(text, cls = "") {
  $("status").textContent = text;
  $("status").className = cls;
}

function li(text, cls = "") {
  const el = document.createElement("li");
  el.textContent = text;
  if (cls) el.className = cls;
  return el;
}

function showInstruction() {
  const t = tasks.find((x) => x.name === $("task").value);
  $("instruction").value = t ? t.instruction : "";
}

async function loadTasks() {
  tasks = await (await fetch("/api/tasks")).json();
  $("task").replaceChildren(...tasks.map((t) => new Option(t.name, t.name)));
  showInstruction();
}

$("task").addEventListener("change", showInstruction);

$("run").addEventListener("submit", async (e) => {
  e.preventDefault();
  const body = {
    task: $("task").value,
    seed: Number($("seed").value),
    max_steps: Number($("max_steps").value),
    show_positions: $("show_positions").checked,
    instruction: $("instruction").value.trim() || null,
  };
  const r = await fetch("/api/run", {
    method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body),
  });
  if (!r.ok) {
    setStatus(`error: ${(await r.json()).detail}`, "bad");
    return;
  }
  $("steps").replaceChildren();
  $("todo").replaceChildren();
  $("notes").textContent = "";
  setStatus("starting");
});

$("stop").addEventListener("click", () => fetch("/api/stop", { method: "POST" }));

function onEvent(ev) {
  if (ev.kind === "observation") {
    $("top").src = `data:image/png;base64,${ev.top_png}`;
    setStatus(`step ${ev.step}: thinking`);
  } else if (ev.kind === "reply") {
    setStatus(`step ${ev.step}: moving`);
  } else if (ev.kind === "step") {
    const item = li(`Step ${ev.step}`, ev.success ? "success" : "");
    const detail = document.createElement("ul");
    detail.append(li(`Saw: ${ev.observation}`), li(`Plan: ${ev.plan}`), ...ev.results.map((r) => li(r, "result")));
    if (ev.truncated) detail.append(li("Plan cut to 8 actions", "bad"));
    item.append(detail);
    $("steps").prepend(item);
    $("todo").replaceChildren(...ev.todo.map((t) => li(t)));
    $("notes").textContent = ev.notes;
  } else if (ev.kind === "bad_reply") {
    $("steps").prepend(li(`Step ${ev.step}: bad reply (${ev.error})`, "bad"));
  } else if (ev.kind === "llm_error") {
    setStatus(`model error: ${ev.message}`, "bad");
  } else if (ev.kind === "run_end") {
    if (ev.status === "success") setStatus("SUCCESS", "success");
    else setStatus(`ended: ${ev.status}${ev.message ? ` (${ev.message})` : ""}`, ev.status === "error" ? "bad" : "");
  }
}

function connect() {
  const ws = new WebSocket(`ws://${location.host}/ws`);
  ws.onmessage = (m) => {
    const msg = JSON.parse(m.data);
    if (msg.type === "frame") $("live").src = `data:image/jpeg;base64,${msg.jpg}`;
    else if (msg.type === "event") onEvent(msg);
  };
  ws.onclose = () => setTimeout(connect, 1000);
}

loadTasks();
connect();
```

````markdown
# arm-mind

An LLM controls a simulated robot arm. Pick a task, change the instruction if you want, press Start, and watch Claude move a Franka Panda arm in MuJoCo. The physics stops while Claude thinks, so a slow model is not a problem.

## Setup (WSL2 or Linux)

    uv sync
    ./scripts/fetch_assets.sh     # downloads the Panda model from MuJoCo Menagerie (Apache 2.0)
    uv run armmind scripted --task stack --seed 0   # checks the arm without a model

You also need the Claude Code CLI, logged in. arm-mind uses it as the model backend. No API key is necessary.

## Run

    uv run armmind serve          # then open http://127.0.0.1:8780

Pick a task (reach, pick or stack), a seed and a step limit, then press Start. You can change the instruction text. The success check of the task stays the same. The left side shows the front camera live and the top camera from the last step. The right side shows Claude's to-do list, notes and each step.

The debug switch gives Claude the true cube positions. Use it to find out if a failure comes from vision or from planning.

## How it works

Each step: the app renders a front and a top camera image with a grid on the table. Claude gets the images and the gripper position, and replies with up to 8 actions: `move_to [x, y, z]`, `open`, `close`, `wait`. Code finds the joint angles (IK) and moves the arm. Each result (reached, blocked or unreachable) goes into the next prompt.

Each run writes `runs/<time>/events.jsonl` and the observation images.

## Development

    ./scripts/check.sh

Tests marked `assets` skip when the Panda model is missing.

## License

MIT. The Panda model is not in this repository. MuJoCo Menagerie supplies it under Apache 2.0.
````
